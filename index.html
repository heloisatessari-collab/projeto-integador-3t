EXPERIÊNCIA 01

O universo das ondas eletromagnéticas

A luz visível é apenas uma pequena parte de um conjunto muito maior de radiações que existem no universo.

O que são ondas eletromagnéticas?

São oscilações dos campos elétrico e magnético que transportam energia pelo espaço. Diferentemente das ondas sonoras, elas não precisam de um meio material para se propagar.

No vácuo, todas as ondas eletromagnéticas se propagam à mesma velocidade: aproximadamente 300 mil quilômetros por segundo.

RELAÇÃO FUNDAMENTAL
c = λ × f

Velocidade da luz = comprimento de onda × frequência

EXPERIÊNCIA 02

A temperatura também produz luz.

Todo corpo com temperatura acima do zero absoluto emite radiação eletromagnética.

🔥

Radiação do corpo negro

O corpo negro é um modelo físico ideal que absorve toda a radiação que recebe. Quando aquecido, ele também emite radiação, cuja distribuição depende de sua temperatura.

Esse estudo foi fundamental para o desenvolvimento da Física Quântica, especialmente com os trabalhos de Max Planck.

LEI DO DESLOCAMENTO DE WIEN
λmáx = b / T

Quanto maior a temperatura, menor o comprimento de onda de máxima emissão.

LUZ INCIDINDO SOBRE UM MATERIAL

O que acontece?

Quando a luz incide sobre determinados materiais, seus fótons podem transferir energia aos elétrons. Se a energia recebida for suficiente para superar a função trabalho do material, ocorre a emissão de elétrons.

Einstein explicou esse fenômeno em 1905, mostrando que a energia da luz está relacionada à frequência dos fótons.

EQUAÇÃO DE EINSTEIN
Ec = h × f − Φ

Energia cinética máxima = energia do fóton menos a função trabalho.

PROGRAMAÇÃO DO PROTÓTIPO

Como vamos programar o Arduino?

A lógica será comparar a luminosidade captada pelos sensores e movimentar os servomotores quando houver diferença significativa.

ARDUINO IDE LINGUAGEM C++ 

#include <Servo.h>

Servo motorHorizontal;

const int sensorEsquerda = A0;
const int sensorDireita = A1;

int posicao = 90;
int tolerancia = 30;

void setup() {

    motorHorizontal.attach(9);

    motorHorizontal.write(posicao);

    Serial.begin(9600);

}

void loop() {

    int esquerda = analogRead(sensorEsquerda);
    int direita = analogRead(sensorDireita);

    int diferenca = esquerda - direita;

    if (diferenca > tolerancia) {

        posicao++;

    }

    else if (diferenca < -tolerancia) {

        posicao--;

    }

    posicao = constrain(posicao, 0, 180);

    motorHorizontal.write(posicao);

    Serial.print("Esquerda: ");
    Serial.print(esquerda);

    Serial.print(" | Direita: ");
    Serial.println(direita);

    delay(50);

}

Exemplo didático de controle horizontal. O circuito real deverá incluir alimentação adequada, montagem dos sensores e calibração dos limites dos motores.
